Project Overview

6sp Team Homepage

Building a collaborative team homepage using HTML and GitHub.

About Our Project

6sp is a team project focused on learning collaborative software development.

Our team aims to design and develop a homepage that introduces our members, project goals, and development timeline.

Through this project, we will practice Git branching, committing, pull requests, and collaborative development workflows.

Why This Project Matters

This project helps us understand how developers collaborate using GitHub.
